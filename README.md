# Portfolio Website

This project is a portfolio website designed to showcase skills, projects, and contact information. It is built using HTML, CSS, and JavaScript, following best practices for accessibility and SEO.

## Project Structure

```
portfolio-website
├── src
│   ├── index.html        # Main HTML structure of the portfolio website
│   ├── css
│   │   └── styles.css    # CSS styles for layout, colors, typography, and responsive design
│   ├── js
│   │   └── main.js       # JavaScript for interactivity, including navigation and form validation
│   └── assets            # Directory for images, icons, or other media files
├── package.json          # npm configuration file listing dependencies and scripts
└── README.md             # Documentation for the project
```

## Setup Instructions

1. Clone the repository:
   ```
   git clone Web_Dev_Intro
   ```

2. Navigate to the project directory:
   ```
   cd Web_Dev_Intro
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Open `src/index.html` in a web browser to view the portfolio website.

## Features

- Responsive design that adapts to different screen sizes.
- Smooth scrolling for navigation links.
- Interactive contact form with validation.
- Filterable project section with a lightbox effect for images.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- npm
